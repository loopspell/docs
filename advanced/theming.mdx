Loopspell's theme is built with Sass and compiles automatically on every GitHub Pages build. You can customize colors, fonts, spacing, and layout by editing Sass files directly in your repository — no local build tools needed for simple changes.

## Understanding the File Structure

The following files control your blog's appearance:

```
style.scss          ← Main stylesheet entry point
_sass/
  _variables.scss   ← Colors, fonts, breakpoints
  _highlights.scss  ← Syntax highlighting colors
  _reset.scss       ← CSS reset
  _svg-icons.scss   ← Footer icon styles
```

Start with `_variables.scss` for most customizations. Edit `style.scss` directly for structural or layout changes that go beyond what variables expose.

## Changing Colors

Open `_sass/_variables.scss` to find the color variables that control your entire site palette:

```scss _variables.scss
$blue: #4183C4;     // Link color
$darkerGray: #222;  // Headings
$darkGray: #333;    // Body text
$gray: #666;        // Secondary text
$lightGray: #eee;   // Borders, backgrounds
$white: #fff;       // Page background
```

Change `$blue` to update all links and accent colors across the site in one edit. For example, to switch to a teal accent:

```scss _variables.scss
$blue: #00897B;
```

Commit the change, and GitHub Pages rebuilds your site with the new color applied everywhere.

## Changing Fonts

The font stack variables are also defined in `_sass/_variables.scss`:

```scss _variables.scss
$helvetica: Helvetica, Arial, sans-serif;
$helveticaNeue: "Helvetica Neue", Helvetica, Arial, sans-serif;
$georgia: Georgia, serif;
```

To use a Google Font, add the `@import` at the top of `style.scss` — before the Sass partials are imported — then override the relevant variable:

```scss style.scss
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@300;400;700&display=swap');
```

Then in `_sass/_variables.scss`, update the font stack you want to replace:

```scss _variables.scss
$helveticaNeue: "Inter", "Helvetica Neue", Helvetica, Arial, sans-serif;
```

Headings and body text pick up the new font on the next build.

## Using Alternative Jekyll Themes

Other Jekyll themes designed for GitHub Pages — such as [Hyde](https://github.com/poole/hyde), [Lanyon](https://github.com/poole/lanyon), and [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) — can replace Loopspell's default theme entirely. To switch themes, replace the `_sass/`, `_layouts/`, and `_includes/` folders in your repository with the theme's versions, then update `_config.yml` as the new theme requires.

Refer to [GitHub's theme documentation](https://docs.github.com/en/pages/setting-up-a-github-pages-site-with-jekyll/adding-a-theme-to-your-github-pages-site-using-jekyll) for step-by-step instructions on adding a theme to a GitHub Pages site.

<Warning>
  Editing theme files directly means you own all the styles — you won't automatically receive upstream theme updates. Keep a backup of your original `_sass/`, `_layouts/`, and `_includes/` folders before making major changes so you can roll back if needed.
</Warning>
