Loopspell is a Jekyll-based blogging platform that uses GitHub Pages for completely free hosting. Instead of wrestling with Ruby environments, gem installs, or terminal commands, you start by forking a single repository on GitHub.com — and your blog is live. The entire fork-first workflow happens in the browser: no command line, no local dependencies, no configuration headaches.

## How It Works

Loopspell turns GitHub into your entire blogging workflow. First, you **fork** the Loopspell repository into your own GitHub account and rename it to match your username — that single action creates your live site URL. Next, you **configure** your blog by editing `_config.yml` directly in the GitHub browser editor: set your blog name, description, and avatar. Every save triggers an automatic rebuild. Then you **write** posts by creating Markdown files in the `/_posts/` folder — again, entirely in the browser. Finally, GitHub Pages **publishes** each commit automatically, so your latest post goes live within seconds of hitting "Commit changes." No build commands, no deploys, no pipelines to manage.

<Tip>
  For a richer writing experience, try [Prose.io](http://prose.io) — a free, browser-based Markdown editor built specifically for Jekyll and GitHub Pages. It gives you a live preview, draft support, and easy image uploads without leaving your browser.
</Tip>
